Privacy Policy – Tracking Guard

1. General Information

Tracking Guard is a browser extension designed to improve user privacy by removing known tracking parameters from URLs.

The protection of user privacy is a core principle of this extension.

2. Data Processing

Tracking Guard processes URLs to detect and remove known tracking parameters.

All processing takes place locally on the user's device. No visited URLs, browsing history, or personal data are transmitted to external servers.

3. Stored Data

Tracking Guard may store local settings and usage statistics, such as the number of cleaned URLs or user preferences.

These stored data remain on the user's device and are not accessible by the developer or third parties.

4. Data Sharing

Tracking Guard does not sell, transfer, or share user data with third parties.

User data is not used for purposes unrelated to the extension's primary function.

5. Permissions

Tracking Guard uses browser permissions only for its core functionality:

  • Detecting and cleaning tracking parameters in URLs
  • Saving local settings
  • Providing optional features such as context menu actions

6. Remote Code

Tracking Guard does not use remote code. All JavaScript and other resources are included directly within the extension package.

7. Changes to This Privacy Policy

This privacy policy may be updated if the functionality of the extension or legal requirements change.
